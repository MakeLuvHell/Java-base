# 首页公告弹窗功能 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在 RuoYi-Vue 首页登录后自动弹出公告弹窗，关闭后标记已读。

**Architecture:** 基于现有 `sys_notice` / `sys_notice_read` 表和 `SysNoticeController`，仅在后端添加 Swagger 注解 + 扩大 SpringDoc 扫描范围；前端在 `index.vue` 内嵌公告弹窗组件，调用已有 `listNoticeTop` / `markNoticeRead` API。

**Tech Stack:** Spring Boot 4.x + SpringDoc 3.0.3 + Vue 2 + Element UI

## Global Constraints

- PostgreSQL，所有 DDL 使用 PG 语法（`GENERATED BY DEFAULT AS IDENTITY`、`TIMESTAMP`、`TEXT`）
- 遵循 RuoYi 现有代码风格：Controller extends BaseController、Service 接口分离、Mapper + XML
- SpringDoc 注解使用 `io.swagger.v3.oas.annotations` 包（`@Tag`、`@Operation`）
- 前端 API 调用使用 `ruoyi-ui/src/utils/request` 封装的 `request` 函数

### Task 3: 前端 — index.vue 新增公告弹窗

**Files:**
- Modify: `ruoyi-ui/src/views/index.vue`

**Interfaces:**
- Consumes: `listNoticeTop()` 返回 `[{ noticeId, noticeTitle, noticeContent, isRead, ... }]`，`markNoticeRead(noticeId)` 返回 `{ code: 200, msg: "操作成功" }`

- [ ] **Step 1: 读取当前 index.vue 内容**

- [ ] **Step 2: 在 `<template>` 中新增弹窗组件**

在 `<div class="index">` 内末尾添加：

```vue
<el-dialog
  title="系统公告"
  :visible.sync="noticeDialogVisible"
  width="600px"
  top="8vh"
  @close="handleNoticeClose"
  append-to-body>
  <div v-if="currentNotice">
    <h3 style="margin-bottom: 12px;">{{ currentNotice.noticeTitle }}</h3>
    <div class="notice-content" v-html="currentNotice.noticeContent" />
  </div>
</el-dialog>
```

- [ ] **Step 3: 在 `<script>` 中引入 API 并添加 data / methods**

在 `<script>` 顶部加入 import：

```js
import { listNoticeTop, markNoticeRead } from "@/api/system/notice";
```

在 `data()` 中新增：

```js
noticeDialogVisible: false,
noticeList: [],
currentNotice: null,
noticeIndex: 0
```

在 `created()` 或 `mounted()` 钩子中调用：

```js
this.fetchUnreadNotices();
```

在 `methods` 中添加：

```js
fetchUnreadNotices() {
  listNoticeTop().then(res => {
    const unreadList = (res.data || []).filter(n => !n.isRead);
    if (unreadList.length > 0) {
      this.noticeList = unreadList;
      this.noticeIndex = 0;
      this.showNotice(0);
    }
  });
},
showNotice(index) {
  if (index < this.noticeList.length) {
    this.currentNotice = this.noticeList[index];
    this.noticeDialogVisible = true;
  }
},
handleNoticeClose() {
  const notice = this.currentNotice;
  if (notice && notice.noticeId) {
    markNoticeRead(notice.noticeId).then(() => {
      this.noticeIndex++;
      setTimeout(() => this.showNotice(this.noticeIndex), 300);
    });
  }
}
```
