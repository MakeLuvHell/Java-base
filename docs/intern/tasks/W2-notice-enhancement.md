## 0. 大白话：你要交付什么？

系统里已有 **通知公告**（菜单一般在 **系统管理 → 通知公告**）。  
你要给公告增加 **「是否置顶」** 能力：

- 编辑公告时可以勾选「置顶」；  
- 列表里置顶的公告排在前面；  
- 没有权限的人不能通过接口改公告（返回 **403**，不是只藏按钮）。  

可选加分：按是否置顶筛选、过期时间等——**先完成必做再做可选**。

## 2. 必做功能（P0）与可选（P1）

### P0 必做

| # | 需求 | 验收直观标准 |
| --- | --- | --- |
| 1 | 数据上能表示「是否置顶」 | 库表或字段有置顶标记；新建/编辑可保存 |
| 2 | 列表默认置顶在前 | 两条公告，置顶的那条更靠前 |
| 3 | 管理端 UI | 列表能看到置顶状态；表单能改 |

| # | 需求 |
| --- | --- |

| 7 | 保持与现有 `@Log` 操作日志风格一致 |

**导师可在下达时写明：** 只做 P0 / P0+筛选。

## 4. 推荐实现顺序（按天）

### 第 1 天：读懂现有公告 + 交设计

1. 运行系统，手动把公告 **新增 / 修改 / 删除 / 列表** 各点一遍。  
2. 打开 `SysNoticeController`，把每个接口的：  
   - URL  
   - 权限字符  
   - 对应 Service 方法  
   记在笔记里。  
3. 打开前端 `notice` 页面，找到 `list` / `add` / `update` 调用。  
4. 提交设计，等导师确认。  

### 第 2 天：数据库 + 后端 Domain/Mapper

1. 在**本地**库执行导师确认过的 `ALTER TABLE`（先备份或确认库可丢）。  
2. Java 实体类增加字段 + getter/setter（或与项目 lombok 风格一致）。  
3. Mapper XML：  
   - `insert` / `update` 带上新字段；  
   - `select` 列表查询带上新字段；  
   - `order by` 置顶优先（注意与项目已有排序字段协调）。  
4. 用 Swagger 或接口工具先测后端（若前端未改完）。  

**零基础提示：** 先复制现有字段（如 `status`）在 XML 里出现的位置，再照猫画虎加 `is_top`（字段名以设计为准）。

### 第 3 天：Service / Controller 与权限

1. 确认编辑、新增接口仍有 `@PreAuthorize`。  
2. 不要删除权限注解。  
3. 参数校验：置顶值合法即可（0/1 或 true/false，与项目风格一致）。  
4. 自测：  
   - 管理员可改；  
   - 用无权限账号（或暂时去掉角色菜单后的测试用户）调接口应 403。  

### 第 4 天：前端

1. `api/system/notice.js`：若有明确字段对象，保证提交带上置顶。  
2. 列表页：加一列显示置顶（可用标签「是/否」）。  
3. 表单：加开关。  
4. 查询条件（若做 P1）：加下拉。  
5. 按钮上的 `v-hasPermi` 与后端权限字符保持一致（有则核对）。  

### 第 5 天：联调、自测、提 PR

按第 6 节自测步骤全部走完 → 填写 PR 描述 → 请导师 Review。

## 6. 自测步骤（请原样写进 PR）

1. 确认本地已执行本任务 SQL。  
2. 启动 Redis、MySQL、后端、前端。  
3. 管理员登录 → 通知公告。  
4. 新建公告 A（不置顶）、B（置顶）→ 保存。  
5. 列表中 B 应在 A 前（或按你文档声明的规则）。  
6. 修改 A 为置顶 → 顺序变化符合预期。  
7. 使用**无公告编辑权限**的用户：  
   - 界面上编辑入口应不可用或不可见；  
   - 用浏览器/Swagger **直调**修改接口 → 期望 **403**。  
8. 回归：删除、查询原有功能仍可用。

## 9. 常见坑（零基础高频）

| 坑 | 处理 |
| --- | --- |
| 只改了前端，数据库没字段 | 先改库和后端，再改前端 |
| 只改了实体，XML 没改 | 列表永远查不出新字段 |
| 排序只在前端 sort | 换页后顺序错；应在 SQL 层处理（本任务要求） |
| 去掉 `@PreAuthorize` 图省事 | **验收不合格** |
| 提交了 `application-druid.yml` 密码 | 立刻从提交中去掉并轮换密码 |
| 字段命名和数据库驼峰/下划线不一致 | 对照项目现有字段映射方式 |
