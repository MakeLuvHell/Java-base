## 0. 本周目标

1. **15 分钟 Demo**（可录屏）：环境 → 登录 → 公告置顶/筛选/导出 → 有无权限对比。

3. **PR 合入**：按导师要求把 W2/W3 功能合入 `master`（或团队主分支）。

## 1. Demo 脚本（建议 15 分钟）

| 分钟 | 内容 | 你要说的话（提示） |
| --- | --- | --- |
| 0–2 | 架构一句话 | 前后端分离；MySQL 存业务；Redis 存登录会话 |
| 2–4 | 登录 | 验证码 → Token → 后续 Authorization |
| 4–7 | 用户列表跟读结论 | 路径：页面 → API → Controller → 权限字符 |
