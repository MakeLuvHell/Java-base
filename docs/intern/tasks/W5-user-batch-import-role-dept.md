## 0. 大白话：本周你要交付什么？

在 **系统管理 → 用户管理** 页面，实习生要能完成以下操作：

| 能力 | 用户能感知到什么 |
| --- | --- |
| 批量导入 | 点击「导入」按钮，选择 Excel 文件，上传后能看到导入结果（成功/失败行 + 错误原因） |

**一句话验收标准：**  
管理员能批量导入用户并分配部门/角色；无对应权限用户直调接口返回 403。

## 2. 功能详细说明

### 2.1 批量导入
- 点击「导入」按钮（新增按钮或修改现有导入按钮）
- 支持 Excel 文件上传
- 导入成功后返回导入结果表格（包含：行号、状态、错误原因）
- 失败行可标记为**不可导入**（可选）

### 2.2 批量分配部门
- 选中多行用户（支持多选 + 全选）
- 点击「批量分配部门」按钮
- 弹窗显示部门树（`DeptTree`）
- 选择部门后保存，更新选中用户的 `dept_id`

### 2.3 批量分配角色
- 选中多行用户
- 点击「批量分配角色」按钮
- 弹窗多选框选择角色
- 保存后更新 `sys_user_role` 表

## 3. 验收标准
1. 本地能启动后端 + 前端
2. 管理员能**成功批量导入**用户（含部门/角色）
3. 管理员能**批量分配部门**（多选用户 → 选部门 → 保存）
4. 管理员能**批量分配角色**（多选用户 → 选角色 → 保存）
5. 无 `system:user:import` 权限的用户直调导入接口返回 **403**
6. 菜单权限同步更新（若做了菜单修改）
7. PR 描述包含：改动摘要 + 自测步骤 + 截图/接口示例
