## 正文

你好，欢迎加入本项目（RuoYi-Vue / Java-base）实习。

本仓库是一个 **管理后台**（用户、角色、菜单、通知公告等）。开发时要在自己电脑上同时跑：

- **后端**（Java，常见端口 `8080`）
- **前端**（Vue，常见地址 `http://localhost`）
- **MySQL**（存业务数据）
- **Redis**（存登录会话）

如果你几乎没做过完整 Web 项目，**完全正常**。请严格按下面顺序走，不要跳着改安全配置或乱加功能。

### 第 1 周唯一目标

1. 本地能登录系统；  
2. 用**自己的话**讲清登录（验证码 / 密码 / Token / Redis）；  
3. 从「用户管理」跟一遍前后端路径；  
4. 用 Swagger 带 Token 调通一个需登录的接口。

**本周不要做：** 改 JWT 密钥、改生产安全配置、大改 UI、新建复杂业务表。
