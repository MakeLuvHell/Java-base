## 不推荐作为首个独立任务

- 直接轮换生产 JWT secret / 数据库密码策略落地（SEC-001/002）
- 大范围改造 `SecurityConfig` 而不做回归清单
- 在无人值守环境开启代码生成并执行 DDL（SEC-007）
- 无锁文件策略共识下强行提交全量 `node_modules` 或随意 lockfile 策略
