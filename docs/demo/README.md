## 使用建议

1. **周五口头验收**：打开 `W1-oral-qa.md`，任选 ≥6 题；对照「合格要点」，不必要求背类名。  
2. **批改书面作业**：打开 `W1-login-reference.md`，看是否覆盖要点、是否像整段复制 audit。  
3. **W2 设计评审**：用 `W2-notice-reference.md` 第 1 节当「OK 模板」；实习生方案等价即可。  
4. **发现实习生作业与本文一字不差**：要求当面重述 + 指代码，防止抄答案。
